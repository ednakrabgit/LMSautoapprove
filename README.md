# ⚡ ระบบอนุมัติการอบรมอัตโนมัติ (Viriyah Auto Approve Bot) - Multi-Platform Edition

โปรแกรมสำหรับช่วยทำงาน Routine อนุมัติการอบรมบนเว็บไซต์ **Viriyah Online Learning**  
URL: `https://vonlinelearning.viriyah.co.th/admin/trainingEnrollments?activeTab=pendingApproval`

---

## 🎯 รูปแบบ Flow การทำงานที่รองรับ

### 1️⃣ Flow 1: "ผ่านการตรวจสอบ" (Flow เดิม)
1. กรองสถานะหน้าหลักเป็น **"ผ่านการตรวจสอบ"**
2. กด **"ดูรายละเอียด"** เปิดในแท็บใหม่
3. ถ้าพบคำว่า **"ตรวจสอบใบประกาศนียบัตร"** อยู่แล้ว -> **ปิดแท็บทันที**
4. ถ้ายังไม่มี -> กดปุ่ม **"อนุมัติ"** ด้านล่างขวา -> Pop-up กรอกหมายเหตุ "อนุมัติ" -> กด **"ยืนยัน"** -> รอจนขึ้น **"ตรวจสอบใบประกาศนียบัตร"** -> **ปิดแท็บ**
5. กลับมาหน้าหลัก รีเฟรชและทำรายการถัดไป

### 2️⃣ Flow 2: "รออนุมัติ" และ "รออนุมัติ (ครั้งที่ 2)"
1. กรองสถานะหน้าหลักเป็น **"รออนุมัติ"** (รองรับทั้งรายการที่ขึ้นสถานะ `"รออนุมัติ"` และ `"รออนุมัติ (ครั้งที่ 2)"`)
2. กด **"ดูรายละเอียด"** เปิดในแท็บใหม่
3. **ตรวจสอบช่อง "ผลการตรวจสอบ"**:
   - ต้องพบข้อความครบทั้ง 3 ข้อความนี้:
     * `ไม่ได้รับการตรวจสอบจากกรมการปกครอง`
     * `ไม่ได้รับการตรวจสอบการปลอมแปลงภาพถ่ายบัตรประชาชน`
     * `ผ่านการตรวจสอบความถูกต้องจากการอ่านข้อมูลบนบัตรประชาชน`
   - **ถ้าไม่พบข้อความใดข้อความหนึ่ง -> ให้ปิดแท็บนี้ทันทีและข้ามรายการ**
4. กดปุ่ม **"ผ่านการตรวจสอบ"** ด้านขวาล่าง -> Pop-up กรอก "ผ่านการตรวจสอบ" -> กด **"ยืนยัน"**
5. รอจนกว่ามุมขวาล่างจะมีปุ่ม **"อนุมัติ"** -> กดปุ่ม **"อนุมัติ"**
6. Pop-up ขึ้นมา -> กรอกคำว่า "อนุมัติ" -> กด **"ยืนยัน"**
7. รอจนกว่ามุมขวาล่างจะขึ้นคำว่า **"ตรวจสอบใบประกาศนียบัตร"** -> **ปิดแท็บ**
8. กลับมาหน้าหลัก รีเฟรชและทำรายการถัดไป

## 🚀 วิธีการเปิดใช้งาน

### 🪟 สำหรับ Windows (Portable / Zero-Install):
1. ดับเบิ้ลคลิกไฟล์ **`run.bat`**
2. หน้าต่างโปรแกรมจะเปิดขึ้นมาทันทีโดยไม่ต้องติดตั้งอะไรเพิ่ม

---

### 🍏 สำหรับ Mac (macOS):
1. **เปิดครั้งแรก:** เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์คำสั่งให้สิทธิ์การรัน (ทำครั้งเดียว):
   ```bash
   chmod +x run_mac.command run_mac.sh
   ```
2. **การเปิดใช้งาน:**
   - **วิธีที่ 1 (สะดวกที่สุด):** ดับเบิ้ลคลิกไฟล์ **`run_mac.command`**
   - **วิธีที่ 2:** เปิด Terminal แล้วพิมพ์ `./run_mac.sh`
3. สคริปต์จะตรวจสอบและติดตั้งสภาพแวดล้อมอัตโนมัติ จากนั้นหน้าต่างโปรแกรมจะเปิดขึ้นมาพร้อมใช้งานทันทีครับ
