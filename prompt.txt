【คำสั่งสร้างระบบ Desktop Automation App สำหรับ Viriyah Online Learning】

ช่วยพัฒนาโปรแกรม Desktop Application ด้วย Python + Playwright + CustomTkinter สำหรับทำ Routine งานอนุมัติการอบรมบนเว็บไซต์ของบริษัท วิริยะประกันภัย โดยมีรายละเอียดความต้องการทั้งหมดดังนี้:

1. ข้อมูลเว็บไซต์และการ Login:
   - URL เป้าหมาย: https://vonlinelearning.viriyah.co.th/admin/trainingEnrollments?activeTab=pendingApproval
   - ใช้ Persistent Context (โฟลเดอร์ browser_profile) เพื่อบันทึก Session การล็อกอินไว้ในเครื่อง
   - เมื่อเริ่มโปรแกรม หากยังไม่ได้ล็อกอิน ให้ระบบรอให้ผู้ใช้ล็อกอินในหน้าต่างเบราว์เซอร์ให้สำเร็จก่อนเริ่มทำงานอัตโนมัติ

2. เมนูเลือก Flow การทำงาน (Multi-Flow Support):
   ก่อนกดเริ่มทำงาน ให้มีเมนูเลือก Flow ได้ 2 รูปแบบ:

   ▶ Flow 1: "ผ่านการตรวจสอบ"
     1) ที่หน้าหลัก เลือกตัวกรองสถานะเป็น 'ผ่านการตรวจสอบ'
     2) กดปุ่ม 'ดูรายละเอียด' ท้ายรายการ โดยเปิดเป็นแท็บใหม่ (New Tab)
     3) ตรวจสอบแท็บใหม่: หากตรวจพบคำว่า 'ตรวจสอบใบประกาศนียบัตร' อยู่แล้ว -> ให้ปิดแท็บทันที (ข้ามรายการ)
     4) หากยังไม่มี -> เลื่อนไปกดปุ่ม 'อนุมัติ' ด้านล่างขวา
     5) เมื่อมี Pop-up หมายเหตุ -> กรอกคำว่า 'อนุมัติ' -> กดปุ่ม 'ยืนยัน' ที่มุมบนขวา
     6) รอจนกว่าปุ่มมุมขวาล่างจะเปลี่ยนเป็นคำว่า 'ตรวจสอบใบประกาศนียบัตร'
     7) ปิดแท็บรายละเอียด สลับกลับมาหน้าหลัก ทำการ Refresh หน้าเว็บ และดำเนินการรายการถัดไป

   ▶ Flow 2: "รออนุมัติ"
     1) ที่หน้าหลัก เลือกตัวกรองสถานะเป็น 'รออนุมัติ'
     2) กดปุ่ม 'ดูรายละเอียด' ท้ายรายการ โดยเปิดเป็นแท็บใหม่ (New Tab)
     3) ตรวจสอบเงื่อนไขในช่อง 'ผลการตรวจสอบ':
        - ต้องพบข้อความครบถ้วนทั้ง 3 ข้อความนี้:
          * "ไม่ได้รับการตรวจสอบจากกรมการปกครอง"
          * "ไม่ได้รับการตรวจสอบการปลอมแปลงภาพถ่ายบัตรประชาชน"
          * "ผ่านการตรวจสอบความถูกต้องจากการอ่านข้อมูลบนบัตรประชาชน"
        - หากไม่พบข้อความใดข้อความหนึ่ง (ขาดไป หรือมีข้อความเตือนอื่น) -> ให้ปิดแท็บนี้ทันทีและข้ามรายการ
     4) หากผ่านเกณฑ์ทั้ง 3 ข้อความ -> กดปุ่ม 'ผ่านการตรวจสอบ' ด้านขวาล่าง
     5) Pop-up ขึ้นมา -> กรอกคำว่า 'ผ่านการตรวจสอบ' ในช่องหมายเหตุ -> กดยืนยันที่มุมบนขวา
     6) รอจนกระทั่งปุ่มด้านขวาล่างเปลี่ยนเป็นคำว่า 'อนุมัติ' -> กดปุ่ม 'อนุมัติ'
     7) Pop-up ขึ้นมา -> กรอกคำว่า 'อนุมัติ' ในช่องหมายเหตุ -> กดยืนยันที่มุมบนขวา
     8) รอจนกระทั่งปุ่มด้านขวาล่างเปลี่ยนเป็นคำว่า 'ตรวจสอบใบประกาศนียบัตร' -> ปิดแท็บ
     9) สลับกลับมาหน้าหลัก ทำการ Refresh และทำรายการถัดไปจนครบ

3. หน้าต่างโปรแกรมและการควบคุม (GUI & Controls):
   - ออกแบบหน้าตา Modern GUI สวยงามด้วย CustomTkinter
   - มี Dropdown เลือก Flow 1 หรือ Flow 2 พร้อมคำอธิบายย่อที่เปลี่ยนตามตัวเลือก
   - ช่องตั้งค่า: ข้อความหมายเหตุ, กำหนดจำนวนที่ต้องการทำ (0 = ทั้งหมด), หน่วงเวลา (วินาที)
   - ปุ่มควบคุม: ▶️ เริ่มทำงาน (Start), ⏸️ หยุดชั่วคราว (Pause), ⏹️ ยกเลิก / หยุด (Stop)
   - แถบสถานะ (Status Label) และ Live Log แบบเรียลไทม์ พร้อมตัวนับจำนวนที่ทำสำเร็จ
   - ทำงานแบบ Multi-threading เพื่อไม่ให้หน้าต่างโปรแกรมค้างขณะบอทกำลังรัน

4. โครงสร้างแบบ Portable (Zero-Install):
   - รวมไฟล์ runtime และเบราว์เซอร์ Chromium ไว้ในโฟลเดอร์ ให้สามารถยกทั้งโฟลเดอร์ไปเปิดใช้งานบนคอมพิวเตอร์ Windows เครื่องอื่นได้ทันทีโดยไม่ต้องติดตั้ง Python หรือดาวน์โหลดอะไรเพิ่ม
   - ไฟล์ run.bat ที่เปิดโปรแกรมได้แบบ One-Click
